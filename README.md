# Historian Chatbot

AI-powered chatbot built with React, TypeScript, and Python (FastAPI).

The app allows users to chat with an AI historian that answers questions with historical accuracy, adds related facts, and uses humor — adapting its style to the language of the user.

Responses are generated by the GPT OSS 120B model via the Groq API.

## Features

- Conversational AI with full message history (context-aware responses)
- Expert historian persona with didactic style
- 50-word limit per response for concise answers
- Real-time loading indicator while awaiting response
- Error handling for failed requests
- Responsive layout

## Tech Stack

**Frontend**

- React + TypeScript
- Vite
- Tailwind CSS

**Backend**

- Python + FastAPI
- Groq SDK (GPT-OSS-120b)
- Uvicorn

## Quick Start

**Backend**

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file inside `backend/`:

```
GROQ_API_KEY=your_api_key_here
```

```
uvicorn main:app --reload
```

**Frontend**

```
cd frontend
npm install
npm run dev
```
