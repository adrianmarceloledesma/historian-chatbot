## Featured Project

An AI-powered chatbot specialized in history, built with React, FastAPI, and Groq.

## Tech Stack

**Frontend:**

- React 19 + TypeScript
- Vite
- TailwindCSS
- HTML/CSS

**Backend:**

- Python
- FastAPI

**Tools:**

- Git
- GitHub
- Vercel (Deployment)
- Railway (Deployment)

**Key Features:**

- Conversational AI powered by Groq (Llama 3.3 70B)
- Full conversation memory
- Responsive design (mobile-first)
- Dark theme with modern UI

**Tech Used:**

```
React • TypeScript • Vite • TailwindCSS • FastAPI • Python • Groq API
```

**Demo:** [The Historian](https://historian-chatbot.vercel.app)
